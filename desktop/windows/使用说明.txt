局中事 · Windows 版

支持 Windows 10、Windows 11 的 64 位（x64）电脑。请使用近期版本的 Edge、Chrome 或 Firefox 浏览器。

1. 在 ZIP 文件上右键，选择“全部解压缩”。
2. 打开解压后的文件夹，双击带亮窗图标的“局中事.exe”。
3. 游戏会在默认浏览器中打开，可离线游玩。请保留“局中事”启动窗口。
4. 如关闭了网页，点击启动窗口里的“打开游戏”即可返回。退出时点击“退出游戏”。

游戏会自动保存。下次打开后，可在主菜单继续生涯。存档和设置保存在当前 Windows 账户的 %LOCALAPPDATA%\局中事。更新游戏时可重新解压至另一文件夹。
